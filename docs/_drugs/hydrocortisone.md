# Hydrocortisone: From Topical Anti-Itch/Eczema Use to Alopecia Areata

## One-Sentence Summary

Hydrocortisone is a glucocorticoid marketed in the US mainly as topical products (creams, lotions and others), including OTC products labelled for eczema and itch relief.
The TxGNN model predicts it may be effective for **alopecia areata**, with **1 Phase 3 randomized trial** (in which hydrocortisone was the comparator, not the test drug) and **21 publications** retrieved, most of them old or indirect.

## Why is This Prediction Reasonable?

Detailed mechanism-of-action data is not available in the pack. Based on known information, hydrocortisone is a glucocorticoid with anti-inflammatory and immunosuppressive effects. Its efficacy in steroid-responsive skin conditions such as eczema is established, and mechanistically it may be applicable to alopecia areata.

Alopecia areata is a T-cell-mediated autoimmune attack on the hair follicle. Topical and intralesional corticosteroids are an established immunosuppressive approach for it, and this class effect is the basis of the prediction. Historical reports from 1956 to 1966 describe intradermal hydrocortisone injections for alopecia areata, which fits the idea.

The main caveat is potency. The only Phase 3 RCT used hydrocortisone 1% as the low-potency comparator against clobetasol 0.05%. It supports the steroid class effect but does not show that hydrocortisone is a preferred therapy, and the pack does not include the trial outcomes. Any real value would have to be shown against higher-potency steroids or JAK inhibitors.

## Conclusion and Next Steps

**Decision: Hold**

**Rationale:**
The only Phase 3 RCT used hydrocortisone 1% as the low-potency control, so it supports the steroid class effect but not hydrocortisone itself, and no outcomes are available. Higher-potency steroids and JAK inhibitors are the more likely comparators. The other nine predicted indications are L4–L5, and none has clinical evidence supporting hydrocortisone.

**To proceed, the following is needed:**
- Trial outcomes for NCT01453686 and the JAMA Dermatology 2014 paper, to see how hydrocortisone 1% performed against clobetasol
- Package insert warnings and contraindications (a blocking gap for safety screening)
- Detailed mechanism-of-action data from DrugBank
- Approved indication text for the US licenses, to confirm the original indication
- Comparative evidence against higher-potency topical steroids and JAK inhibitors, to show any added value
- Route and formulation assessment (topical vs intralesional) for scalp use
